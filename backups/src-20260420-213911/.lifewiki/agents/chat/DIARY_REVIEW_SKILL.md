# 日记复盘 Skill

## 工具使用

### read_diary_entries

读取指定日期范围内的日记条目。

**输入**:
```json
{
  "startDate": "2026-04-19",
  "endDate": "2026-04-19",
  "query": "可选的搜索关键词"
}
```

**输出**:
```json
{
  "success": true,
  "data": {
    "entries": [
      { "date": "2026-04-19", "content": "日记内容..." }
    ],
    "total": 1
  }
}
```

### summarize_entries

生成格式化日记复盘。

**输入**:
```json
{
  "entries": [
    { "date": "2026-04-19", "content": "日记内容..." }
  ],
  "summaryType": "daily"
}
```

**输出**:
```json
{
  "success": true,
  "data": {
    "summary": "## 第一部分：今日概述\n..."
  }
}
```

## 使用场景

当用户要求：
- "总结今天的日记"
- "生成今日复盘"
- "查看本周日记"
- "本周周报"
- "本月总结"

## 使用流程

1. 先用 `read_diary_entries` 读取日记内容
2. 再用 `summarize_entries` 生成格式化复盘

## 日期快捷表达

| 用户输入 | startDate | endDate |
|---------|-----------|---------|
| 今天 | 今天日期 | 今天日期 |
| 昨天 | 昨天日期 | 昨天日期 |
| 本周 | 本周一 | 今天 |
| 上周 | 上周一 | 上周日 |
| 本月 | 本月1日 | 今天 |
| 上月 | 上月1日 | 上月末 |

## Block ID 忽略说明

日记内容中可能包含以下 block ID 格式，请忽略：
- `<sub ...>uuid</sub>`
- `<!-- uuid -->`

只需要处理有意义的文本内容。

## 复盘格式模板

\`\`\`
## 第一部分：今日概述
- **核心事件**（≤5条，合并同类）
  - 事件摘要 | 涉及人员 | 项目关联

- **工作总结**
  - ✅ 有效投入：...
  - ❌ 无效投入：...

## 第二部分：重要事项进展
- 项目名 | 进展描述 | 状态变化
\`\`\`
